# reference/ 出處索引

每篇衛教文章一個檔案，記錄文章中每個數字與敘述的出處及查核狀態。本目錄不在 `nextjs-app/` 內，不會部署到網站。

本 repo 是公開的：只記錄引用資訊與文章實際用到的數值，不貼論文內文或大段原文，也不放 PDF。

## 檔案清單

| 檔案 | 文章 |
|---|---|
| `normal-pressure-hydrocephalus.md` | 常壓性水腦症（Normal Pressure Hydrocephalus） |

## 條目格式

```
### [ID] 短名
- 完整引用：作者. 篇名. 期刊 年;卷:頁. DOI／URL
- 用於：第 N 節
- 引用內容：文章實際用到的數字或敘述
- 查核：✅ ／ 🔶 ／ ❓，加上查核依據
```

ID：第一作者加年份（`[Jaraj2014]`）；指引用機構加版本（`[JSNPH2021]`）。

## 狀態圖例

- ✅ 全文核對：已讀到全文或官方條文原文。
- 🔶 摘要或二手來源核對：數字一致，但未見原表。可留在文章，須列入 PR 的「請醫師確認」清單。
- ❓ 未能核對：數字不得留在文章，刪除或改為不含數字的敘述。
